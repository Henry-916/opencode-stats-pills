# 统计口径

[English](metrics.md) · [返回 README](../README-zh.md)

## 计算方式

| 指标 | 计算方式 |
| --- | --- |
| 生成速度 | 正文开始流式输出之后生成的输出 Token ÷ 首批正文到模型流结束的累计时长；不含思考 Token，没有正文的步骤不参与 |
| 模型用时 | 模型步骤开始到模型流结束的累计时长，不包含随后执行工具的时间 |
| 平均 TTFT | 有效样本中，步骤开始到首次输出的平均时长 |
| Token 总量 | 会话中已完成模型请求与压缩请求的 `input + cache.read + cache.write + output + reasoning` 之和，不含标题请求 |
| 缓存命中率 | `cache.read / (input + cache.read + cache.write)` |
| 上下文占用 | 最近完成模型请求的输入（含缓存读取、写入）÷ 该请求模型的上下文窗口；不计输出和思考 |

TTFT 的首次输出可以是正文、思考、工具名称或工具参数。OpenCode V2 的 `time.streamed` 表示**模型流结束**，`time.completed` 还可能包含工具执行时间。

### 生成速度为什么只看正文

速度要成立，分子里的 Token 必须是在分母那段时间里生成的。DSH 的口径是「全部输出 Token ÷ 首次输出到流结束」，它假设模型一开始生成，客户端就能看到增量。OpenCode 的事件流不满足这个假设：

- 思考可能完全不可见（只有加密载荷，没有文本）。这些 Token 在首次输出之前就已生成，时间被算成首 Token 等待。
- 工具调用经常整块到达：模型花数秒生成参数，客户端在流结束前几毫秒才看到。
- 短回复可能只有一批增量，这批内容在计时开始前已经生成。

沿用 DSH 口径时，实测一个 41 步的会话读数为 483.7 tok/s，其中 39 个纯工具步骤以 0.4 秒的时长计入了 10,046 个 Token；同一会话的正文实际流速约为 136 tok/s。

因此速度只统计能观察到生成过程的部分：

- 分母是首批正文增量到模型流结束的时长。
- 分子是该步骤的 `output` Token，按字符比例扣除首批正文（它在计时开始前已生成）。`output` 对应正文和工具调用，不含思考。
- 没有正文增量的步骤、正文之前已有工具调用的步骤，不计入分子和分母。

### 数据可用性

- 速度只有一个口径，不包含首 Token 等待或工具执行时间；先累计 Token 和时长再相除，不对每一步的 TPS 取算术平均。
- 不设时长门槛，也不限制读数。只有一批正文的回复没有可测区间，显示 `—`；纯工具调用的会话在出现流式正文之前也显示 `—`。
- 时间戳相同的正文增量视为同一批。首批正文的时间和字符数由插件实时采集并持久保存；OpenCode 的历史记录不保存增量，升级前采集的旧样本只能恢复 TTFT，速度显示 `—`。
- 正文之后、流结束之前生成的工具调用计入速度。夹在正文和工具调用之间的隐藏思考会拉长分母，使读数偏低。
- 读数反映正文和工具调用的可见输出流速，不代表思考阶段的速度，也不代表模型内部每个 Token 的精确生成时间。
- TTFT 的首次输出取非空正文、思考、工具名称或参数增量时间，忽略空块开始通知。采集时间持久保存，历史内容时间戳作为补充。思考不可见时，TTFT 包含思考时间。
- Token 总量和费用来自分页读取的请求明细，按消息 ID 去重，排除标题请求；保留有用量记录的压缩请求。历史未加载完整时用量和费用显示 `—`。
- 外部子代理若没有向 OpenCode 上报用量，插件无法提供其准确 Token 统计。
- 宿主将缓存缺报归一化为零时，无法区分“上游没有上报”和“确实没有命中”。
- 上下文显示最近请求的输入读数，使用该请求模型的窗口；未知时显示 `—`，不会伪装为 `0%`。DSH 还会在此基准上估算后续内容的占用，OpenCode 插件目前未实现这一投影，也无法提供系统提示词、工具定义和消息的准确分类明细。

## 费用

费用单位为美元。自定义价格按每百万 Token 计算：

`((未缓存输入 + 缓存写入) × input + (输出 + 思考) × output + 缓存读取 × cacheRead) / 1,000,000`

各类 Token 互不重叠；思考使用输出价格，缓存写入使用输入价格。每个请求根据其供应商和模型匹配价格，完成的请求按 ID 去重。会话总额不包含子会话。最近一轮对话累计最近一条用户消息之后已完成的模型和压缩请求；尚无已完成请求时显示 `—`。

未配置自定义价格的模型使用 OpenCode 上报的费用。宿主的 `0` 只有在模型价格明确为免费时才显示为免费。自定义价格改变后会重新核算历史请求。费用是估算值，实际账单可能包含折扣或其他收费。

费用只累加同一会话的请求明细，不使用包含标题费用的宿主会话总账。标题不计入 Token、缓存命中率和费用。缺失记录或未定价请求会显示 `—`。配置示例见 [README](../README-zh.md#自定义价格)。
